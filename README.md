# Responsive-Developer-Profile-Card-with-Expandable-Social-Media-Links
Project Description

This project is a modern and interactive personal profile card developed using HTML, CSS, and JavaScript. It displays a profile picture, name, profession, and social media icons in a clean and attractive design. The card features smooth animations, a circular social media menu, and a responsive layout.

How It Works

The profile card displays the user's picture, name, and profession. When the user clicks the circular menu button, JavaScript activates an animated social media menu. Five icons smoothly expand around the right side of the profile card, including Facebook, GitHub, Instagram, LinkedIn, and a coding icon. The menu button changes from a hamburger icon to a close icon. Clicking it again hides the social media icons. CSS controls the animations, positioning, colours, and hover effects.

Technologies Used

HTML: Creates the profile card, image, text, menu button, and social media links.

CSS: Provides the card design, circular layout, animations, hover effects, and responsive styling.

JavaScript: Controls opening and closing the social media menu.

Font Awesome: Provides the menu and social media icons.

Key Features

Interactive profile card

Animated circular social media menu

Smooth opening and closing effects

Responsive design

Social media icon hover effects

Modern and minimal user interface
